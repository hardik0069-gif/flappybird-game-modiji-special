# 🐦 Flappy Bird Modiji special (Python + Pygame)

A Flappy Bird-inspired game developed using **Python** and **Pygame**. This project recreates the classic gameplay where the player controls a bird, avoids obstacles, and scores points by successfully passing through randomly generated pipes.

# ⚙️ Installation

## 1. Clone the Repository

```bash
git clone https://github.com/hardik0069-gif/flappy-bird-pygame.git
```

---

## 2. Navigate to Project Folder

```bash
cd flappy-bird-pygame
```

---

## 3. Install Dependencies

```bash
pip install -r requirements.txt
```

or

```bash
pip install pygame
```

---

## 4. Run the Game

```bash
python main_modiji_special.py
```
